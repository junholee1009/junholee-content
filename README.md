## About

This is my one-page content portfolio, created for opportunities in content creation, social media, and campus communications. It presents two self-initiated short-form projects inspired by my experience as an international exchange student at the University of Missouri–Kansas City.

The portfolio combines visual storytelling with the structured problem-solving perspective I bring from studying Information & Communication Engineering at Dongguk University.

## Featured projects

| Project | Focus | Contribution |
| --- | --- | --- |
| **Colors in UMKC** | Campus identity and everyday student life | Concept development, filming, editing, caption and copy development |
| **Korean Games You Should Try** | Cultural storytelling and event engagement | Content planning, collaboration, filming, editing, and audience-focused storytelling |

Both reels are embedded directly in the website and can also be opened as full videos without signing in.

## What the portfolio demonstrates

- Short-form content planning and production
- Visual storytelling and video editing
- Audience awareness and clear copy
- Cultural and international perspective
- Responsive, accessible web presentation

- Semantic HTML5

## Run locally

Because the portfolio is a static site, it can be opened directly or served with any local web server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The `main` branch is published from the repository root through GitHub Pages.
